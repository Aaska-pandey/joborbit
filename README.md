# JobOrbit 🚀

JobOrbit is a responsive job discovery platform built using HTML, CSS, and vanilla JavaScript. It helps users explore job listings, search for opportunities, filter results, sort jobs, and save interesting listings for later.

## Features

- Browse job listings through a card-based interface.
- Search jobs by title or company.
- Filter jobs by location and employment type.
- Sort jobs by posting date.
- Save and unsave jobs using bookmarks.
- Persist saved jobs with browser localStorage.
- View saved jobs separately.
- Reset filters to return to the complete job list.
- Responsive layout for different screen sizes.

## Tech Stack

- HTML5 — page structure and semantic elements.
- CSS3 — styling, responsive layouts, and focus states.
- JavaScript — search, filtering, sorting, rendering, and event handling.
- DOM APIs — dynamically creating and updating page elements.
- localStorage — saving bookmarked job IDs in the browser.
- Git and GitHub — version control and project hosting.
